# Ночная доставка: бесконечные уровни

Canvas, ванильный JavaScript, ES-модули. Без движка, npm и сборки.

## Запуск
В папке проекта: `python -m http.server 8000`, затем http://localhost:8000.

## Правила
На каждом уровне пять платформ и три письма. Соберите все письма и войдите в дверь, затем нажмите «Следующий уровень». Конечного уровня нет.

Новый маршрут генерируется из номера уровня и случайного ключа серии. Сложность растёт плавно: платформы сужаются, промежутки увеличиваются, высоты меняются. С уровней 4, 7 и 10 добавляются шипы на платформах. Рост ограничен безопасными для прыжка размерами; после этого продолжают генерироваться новые комбинации.

«Повторить» и повтор после поражения сохраняют текущий маршрут. «Новая игра» сбрасывает серию на первый уровень и выбирает новый ключ. Рекорд — максимальный полностью пройденный уровень; хранится в localStorage. Счёт доставленных писем суммируется только при завершении уровня.

Стрелки/A–D — движение, Space/W — прыжок. На телефоне есть экранные кнопки. Прыжок возможен только с опоры. При скрытии вкладки и потере фокуса — пауза.

## Файлы
index.html, style.css, main.js, Game.js, Player.js, input.js, collision.js, level.js.
level.js отвечает за генерацию. Game.js — за переходы, цикл и счёт. Физика обновляется шагами не больше 1/120 секунды; после паузы время сбрасывается.
